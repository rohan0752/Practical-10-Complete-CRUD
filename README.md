# Practical 10: Complete CRUD Operations (Student Management System)

## BCA (Hons.) React.js Practical 10

### 🎯 Objective
To integrate all four core operations—**Create, Read, Update, and Delete (CRUD)**—into a complete, production-grade Student Record Management web application in React with search, filters, statistics, modal dialogs, and undo capabilities.

### 💡 Core Features & Concepts Demonstrated
1. **Create (C)**: Modal dialog form for enrolling new students with complete validation (Roll number uniqueness, email regex, GPA boundaries).
2. **Read (R)**: Real-time searchable, filterable, and sortable data table displaying enrolled students, alongside key KPI statistical cards (Total Enrolled, Active Students, Average GPA).
3. **Update (U)**: Edit modal with pre-populated values and validation for updating student records.
4. **Delete (D)**: Delete confirmation modal with temporary undo toast notification.
5. **Data Reset**: Reset to default dataset at any time for easy grading/evaluation.

### 🚀 Running Locally
```bash
npm install
npm run dev
```

### 📦 Tech Stack
- React 19 / 18
- Vite
- Vanilla Modern Responsive CSS
